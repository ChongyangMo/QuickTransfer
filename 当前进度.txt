当前开发进度

Windows：0.2.1，使用 C# / WPF。
Mac / iPhone：0.1.0，本次未改动苹果端和 Rust 传输协议。

本次改动
- 选择文件后，在待发送区右侧显示“发送”按钮；未选设备或正在发送时自动禁用，清空文件后随待发送区隐藏。
- 待发送文件改为紧凑横向条目，图标或缩略图、文件名、大小与移除按钮并排显示；按数量自适应高度，最多显示两行，更多文件滚动查看。
- 修复深色模式文件名显示为黑色，长文件名省略并可悬停查看；窄窗口自动改为单列。
- 移除顶部“多选”和“发送”按钮；图片勾选、长按框选与 Ctrl + Enter 发送继续可用，按 Esc 退出多选。
- 移除多选栏的“复制”和“添加”按钮，仅保留全选和已选数量；Ctrl + C 批量复制与批量拖出继续可用。
- 修复图库滚动后内容和历史变空：回收的文件卡片重新挂回可视树，接收历史恢复显示。
- 修复图库四周留白不能直接拖拽框选的问题，列间、上下及左右留白统一触发；多选工具栏出现后保持选框起点位置。
- 新增鼠标长按拖拽框选：图片或文件长按约半秒后拖动，空白处直接拉框；支持跨时间分组、边缘自动滚动、Ctrl 增减和 Shift 追加。
- 框选逻辑与选框绘制放在 windows/Controls/Selection/，命中复用瀑布流完整布局，支持滚出视口的图片；保留快速拖出文件。
- 修复后台恢复文件后首次显示窗口时，瀑布流生成器尚未初始化的问题。
- 图片预览按实际可用区域等比居中，默认不显示滚动条；双击或 Ctrl + 滚轮放大后，只在内容超出时显示，恢复后自动隐藏。
- 补上 HEIC / HEIF 图片类型识别，接收历史和待发送列表使用图片缩略图，点击进入内置预览。
- 多选通过图片勾选、长按或空白处框选进入，按 Esc 退出；全选后可“取消全选”，清空选择并保留多选模式。
- “显示”菜单可切换“按时间分组”或连续图片流；切换保留所选文件，选项保存在 settings.json 中。
- 图片目标宽度由 220 缩为约 147，采用 10 像素圆角裁剪，窄窗口和宽窗口自动调整列数。
- 历史图片按传输批次显示真实时间分隔，同批多图不拆开；重启后按接收批次目录恢复分组和时间。
- 新增多选、跨分组连续选择、全选、批量复制和批量拖出；支持 Ctrl、Shift、Esc 快捷操作。
- 时间分隔仍放在原虚拟化瀑布流中，多选和时间整理分别拆到独立文件。
- Windows 构建脚本补上 UTF-8 BOM，兼容系统 Windows PowerShell 的中文脚本解析。
- 当前 Windows 前端工程为 windows/QuickTransfer.csproj，解决方案为 QuickTransfer.slnx。
- 复用 AntoCopy 的通用控件和深浅色配色，主界面改为菜单、设备下拉框与图片流。
- 移除设备、文字和记录的卡片容器；栏目只用分割线分隔。
- 图片采用多列瀑布流，最新内容在左上角，图片文件名只在悬停提示中显示。
- 文字编辑通过菜单打开，默认隐藏；关闭编辑窗口保留草稿。
- 收到的文字独立弹窗，支持选择和复制，不混入图片流。
- 设备列表原位更新，传输进度后台轮询并批量提交到界面。
- 文件元数据和图片解码在后台完成；缩略图按可见卡片加载，最多同时解码两张图片。
- 图片和待发送文件使用回收式虚拟化瀑布流，避免一次生成所有预览。
- 文件拖入、文件卡片拖出和图片预览拖出改用 WPF 标准 OLE 文件拖放。
- 保留剪贴板图片、文件、文字、接收确认、记住设备、托盘、单实例和 Ctrl + Alt + S。
- 支持 Ctrl + Enter 发送；发送成功前保留草稿，失败时不清空。
- 配置、身份私钥、信任列表、已接收文件继续使用原来的本地 QuickTransfer 目录。
- 保存设备名或端口后自动重启服务；传输期间不允许修改设置。
- 发布包自带 .NET 桌面运行时，无需安装 Windows App SDK。
- 旧 WinUI 源码及旧构建产物保留在 build/archive/，当前工程和发布目录没有 WinUI 依赖。

工程说明
- 启动程序：build/windows/x64/Release/QuickTransfer.exe。
- Windows 构建：powershell -File windows/build.ps1；仅重编译界面可加 -SkipCore。
- 工具路径：windows/build.json，使用 .NET 10 SDK 和 Rust 1.99.1 MSVC 工具链。
- 主窗口与剪贴板：windows/MainWindow.xaml、MainWindow.xaml.cs、ClipboardOperations.cs。
- 传输状态：windows/ViewModels/；Rust DLL、缩略图、配置、托盘、广播：windows/Services/。
- 图片与拖出：windows/Controls/FileTile.xaml.cs；瀑布流：windows/Controls/MasonryPanel.cs、MasonryLayout.cs。
- 多选交互：windows/GallerySelection.cs；时间分组：windows/ViewModels/GalleryTimeline.cs、windows/Models/GalleryHeader.cs。
- 拖拽框选：windows/Controls/Selection/GalleryDragSelection.cs、SelectionAdorner.cs。
- 文字编辑和接收弹窗：windows/Views/TextComposeWindow.xaml、ReceivedTextWindow.cs。
- 图片预览：windows/Views/FilePreviewWindow.cs。
- Mac 构建：python3 scripts/build.py mac --configuration Release。
- iPhone 使用 Xcode 的 QuickTransferiOS scheme，或在 Mac 桌面会话运行 scripts/build.py ios --configuration Release。
- Mac 原开发目录：/Users/chongyang/Mac_Project/QuickTransfer。
