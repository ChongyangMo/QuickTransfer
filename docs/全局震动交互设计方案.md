# 快传 iOS 全局震动交互设计方案

基于 `CoreHaptics` 独立串行队列引擎实现，整体采用**高锐度清脆单震为主 + 关键结果/警示双震**的极简干练风格，全应用所有有效点击 100% 覆盖。

## 1. 引擎与生命周期

- 实现文件：`apple/Shared/Haptics.swift`
- 独立串行队列 `com.chongyang.quicktransfer.haptics` 驱动 `CHHapticEngine`（`playsHapticsOnly = true`、`isAutoShutdownEnabled = true`），不阻塞主线程。
- 进入前台自动 `prepare()` 预热，离开前台立刻 `suspend()` 停止所有在播波形；后台通知与自动任务不补播。

## 2. 触感分层（三档清脆单震 + 三种结果双震）

| 档位 / 语义 | 手感性格 | 波形参数（强度 `I` / 锐度 `S`） | 覆盖交互点 |
| --- | --- | --- | --- |
| 轻脆单震（`selection`） | 干脆轻点 | `0ms: I=0.62, S=0.95` | 相册点选/滑选每增减一张、缓存滑动条刻度、缓存快捷天数按钮、记住设备开关 |
| 标准清脆单震（`tap` / `deviceSwitch` / `expand` / `collapse`） | 机械按键感 | `0ms: I=0.76, S=0.95` | 切换设备、「文」展开/收起、「照片」「文件」「设置」「手动添加设备」「完成」「粘贴」「清空」「仅添加」「取消」「预览」等所有常规点击 |
| 有力清脆单震（`pullRefresh` / `action` / `pin` / `confirm`） | 利落主触发 | `0ms: I=0.88, S=0.95` | 下拉刷新触发、右滑/菜单置顶与取消置顶、发起发送、左滑重发、点「接收」、点「连接设备」、保存设置 |
| 叮咚完成双震（`complete`） | 轻脆“叮”+厚重“咚” | `0ms (I=0.56, S=0.96)` → `110ms (I=0.98, S=0.30)` | **发送成功**、复制文字成功、手动清空缓存完成 |
| 沉稳警示双震（`warning`） | 低沉两下 | `0ms (0.90, 0.55)` → `90ms (0.82, 0.45)` | 左滑/菜单删除记录、移除待发送附件、点「立即清理」、拒绝接收、取消传输 |
| 浑厚报错双震（`failure`） | 重锤两下 | `0ms (1.0, 0.40)` → `95ms (1.0, 0.35)` | **发送失败**、读取照片失败、操作错误 |

## 3. 克制原则

- 禁用控件、打字输入、普通列表滚动、自动发现回包和后台事件不触发震动；所有主动有效点击均有清晰、统一、不拖泥带水的触感反馈。
