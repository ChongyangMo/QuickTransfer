# 快传 iOS 全局震动交互设计方案

参考 Yingchui 的 Core Haptics 触感规范制定，统一快传 iOS 端的触觉层次、节奏语义与克制原则。

## 1. 引擎与物理参数

- 实现文件：`apple/Shared/Haptics.swift`
- 技术栈：`CoreHaptics`（`CHHapticEngine`），运行在独立串行队列 `com.chongyang.quicktransfer.haptics`，不阻塞主线程，且 `playsHapticsOnly = true`、`isAutoShutdownEnabled = true`。
- 生命周期联动：
  - App 进入前台（`scenePhase == .active`）自动调用 `Haptics.shared.prepare()` 预热引擎；
  - 离开前台（`.inactive` / `.background`）立即调用 `Haptics.shared.suspend()` 停止并清空播放队列，**后台结果绝不补播**。
- 五级强度表（`sharpness` 统一为 `0.5`，清脆无松散感）：
  - `L1 = 0.2`
  - `L2 = 0.4`
  - `L3 = 0.6`
  - `L4 = 0.8`
  - `L5 = 1.0`
- 双脉冲间隔：统一 `100ms`，由同一个 `CHHapticPattern` 原生调度保证精确时序。

## 2. 语义分级与全页面映射

| 语义（`HapticIntent`） | 强度与节奏 | 快传交互映射 |
| --- | --- | --- |
| `selection` | `L1 (0.2)` | 切换发送目标设备；快速相册单击/滑动多选每增减一张；设置页切换缓存快捷天数、拖动滑动条每档变化；切换“记住此设备”开关 |
| `tap` | `L2 (0.4)` | 普通按钮与图标：右上角“文”展开/收起、“设置”、“照片”、“文件”、“粘贴”、“清空”、“取消选中”、“仅添加”、“系统相册”、关闭错误条、点击传输记录预览 |
| `action` | `L3 (0.6)` | 主要操作与动作触发：**下拉刷新达到触发点**、快速相册一步发送、右滑置顶/取消置顶、左滑重发、接收弹窗点“接收”、手动添加设备点“连接设备” |
| `warning` | `L4 (0.8)` | 危险或破坏性操作：左滑/菜单删除记录、设置页点“立即清理”触发确认、拒绝接收、取消进行中的发送、移除待发送附件 |
| `confirm` | `L3 → L2 (0.6 → 0.4, 100ms)` | 确认型提交：点击“发送”正式发起传输、保存设备设置生效、确认清除发送缓存 |
| `complete` | `L2 → L3 (0.4 → 0.6, 100ms)` | 真实结果完成：**文件/照片/文字真实发送成功**、**下拉刷新完成**、复制文字成功、手动清空缓存完成 |
| `failure` | `L5 (1.0)` | 真实错误与失败：**发送失败**、读取照片/文件失败、配置或连接错误 |

## 3. 下拉刷新双段触感体验

主界面移除顶部刷新按钮，改为全局下拉刷新（设备区顶部与传输记录列表均可下拉）：
1. **下拉触发瞬间**：播放 `action (L3 = 0.6)`，给出干脆明确的“已触发刷新”反馈，同时发起 Rust 核心与 Bonjour 设备重探；
2. **刷新完成回弹**：等待探测周期结束后播放 `complete (L2 → L3, 100ms)`，确认设备列表已更新。

## 4. 克制原则（禁止震动的场景）

以下场景**不主动触发震动**，避免干扰用户：
- 禁用态按钮点击；
- 键盘打字输入字符、普通列表惯性滚动、页面重建刷新；
- 后台自动清理过期缓存、自动设备发现回包、历史记录恢复；
- App 处于后台时收到的通知或传输结果（交由系统通知提示音/震动管理）。
