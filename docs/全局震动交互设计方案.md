# 快传 iOS 全局震动交互设计方案

在 Yingchui Core Haptics 独立队列引擎基础上，针对真机手感抬高起步强度（`>= 0.54`）并扩展为 **12 种高辨识度物理波形**，实现全应用所有可点击交互 100% 触感覆盖。

## 1. 引擎与生命周期

- 实现文件：`apple/Shared/Haptics.swift`
- 独立串行队列 `com.chongyang.quicktransfer.haptics` 驱动 `CHHapticEngine`（`playsHapticsOnly = true`、`isAutoShutdownEnabled = true`），不阻塞主线程。
- 进入前台自动 `prepare()` 预热，离开前台立刻 `suspend()` 停止所有在播波形；后台通知与自动任务不补播。

## 2. 12 种触感花样与全点击映射

| 语义（`HapticIntent`） | 手感性格 | 波形参数（强度 `I` / 锐度 `S`） | 覆盖交互点 |
| --- | --- | --- | --- |
| `selection` | 精密滚轮咔哒 | `0ms: I=0.58, S=0.88` | 相册点选/滑选每增减一张、缓存滑动条刻度、缓存快捷天数按钮、记住设备开关 |
| `deviceSwitch` | 磁吸落位双敲 | `0ms: I=0.56, S=0.68` → `48ms: I=0.80, S=0.92` | 点击切换目标设备 |
| `tap` | 清脆机械按键 | `0ms: I=0.68, S=0.80` | 点击当前设备、「文件」、「粘贴」、「清空」、「仅添加」、「添加」、预览、手动添加设备入口、跳转设置、完成、取消弹窗 |
| `expand` | 抽屉上扬弹开 | `0ms: I=0.54, S=0.45` → `55ms: I=0.74, S=0.80` | 点击「文」展开文字框、点「照片」打开快速相册、打开「设置」、展开「自定义端口」、切系统相册 |
| `collapse` | 轻柔下沉合拢 | `0ms: I=0.68, S=0.75` → `52ms: I=0.50, S=0.40` | 点击「文」或「收起」合拢文字框、收起「自定义端口」、相册 `<` 返回、「取消选中」、关闭设置/弹窗 |
| `pullRefresh` | 清脆干练单震 | `0ms: I=0.86, S=0.95`（仅触发时震一次，不二次补震） | 设备区或传输记录区下拉刷新触发 |
| `pin` | 图钉扎实按入 | `0ms: I=0.80, S=0.35` → `68ms: I=0.88, S=0.92` | 右滑或长按菜单置顶 / 取消置顶 |
| `action` | 扎实主操作键 | `0ms: I=0.84, S=0.72` | 相册一步发送、左滑/菜单重发、接收弹窗「接收」、手动添加「连接设备」 |
| `confirm` | 双拍确认发射 | `0ms: I=0.88, S=0.76` → `85ms: I=0.68, S=0.55` | 主界面「发送」、应用设备更改并重连、确认清空缓存 |
| `complete` | 上扬三连凯旋 | `0ms (0.60, 0.65)` → `65ms (0.78, 0.82)` → `145ms (0.96, 0.92)` | **发送成功**、复制文字成功、清空缓存完成 |
| `warning` | 厚重双敲警示 | `0ms: I=0.92, S=0.42` → `95ms: I=0.84, S=0.34` | 左滑/菜单删除记录、移除待发送附件、点「立即清理」、拒绝接收、取消传输 |
| `failure` | 急促三连报错 | `0ms (1.0, 0.38)` → `75ms (0.95, 0.30)` → `155ms (1.0, 0.24)` | **发送失败**、读取照片失败、操作错误 |

## 3. 克制原则

- 禁用控件、打字输入、普通列表滚动、自动发现回包和后台事件不触发震动；所有主动有效点击均有明确、贴合语义的触感反馈。
